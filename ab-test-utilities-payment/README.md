# A/B-анализ формы оплаты ЖКХ

Аналитический кейс по тестовому заданию Т-Банка. Период данных: 1–30 апреля 2024 года.

- [Итоговый отчёт, PDF](T-bank-AB-report.pdf)
- [Исходные данные, Excel](source-data.xlsx)

## Задача и подход

Сравнение конверсии открытия формы в успешную оплату. Анализ включает проверку качества данных, очистку противоречивых записей и оценку разницы конверсий. Повторные попытки одного клиента учтены с помощью дельта-метода с агрегацией по клиенту и кластерного бутстрэпа.

## Результат

Конверсия A — 49,77%, B — 64,40%. Разница B − A: **+14,63 п.п.**, 95% доверительный интервал: **[10,92; 18,33] п.п.**

Рекомендация — поэтапный запуск B при подтверждении, что B обозначает новую форму, с контролем конверсии, технических отказов и повторных списаний. Соответствие A старой, а B новой форме — допущение кейса.

Это результат анализа тестового задания, а не коммерческий эффект внедрения в Т-Банке.
